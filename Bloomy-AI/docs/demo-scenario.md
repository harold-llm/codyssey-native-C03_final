# 교육과정 제출용 시연

시연 입력은 모두 가상입니다. 화면에는 계획 버전과 승인 상태를 함께 보여 주세요.

| 순서 | 실행 또는 장면 | 확인할 내용 |
|---|---|---|
| 1 | `python -m examples.ai_demo` | 5세 L1·노출 0개월·동물·10분, 7세 L3·노출 18개월·파닉스·15분. 둘 다 평일 20개 카드와 `draft` 상태를 반환합니다. `days[0]`와 `day_details[0]`에서 학습 방법·부모 확인 포인트·추천 이유를 비교합니다. |
| 2 | 같은 출력의 `coach` | 가상 부모 승인 상태에서 학습이 일부 완료되고 이해도가 2점이며 부모 질문이 들어옵니다. C가 B보다 우선하고, 부담 완화가 함께 적용돼 다음 카드가 5분으로 축소됩니다. 근거와 AI 생성 문구를 확인합니다. |
| 3 | `python -m examples.integration_demo` | 초기 초안에서 카드 활성화가 차단됩니다. 모의 승인 다음 10일 피드백을 입력해 A·B·C·휴식일을 확인합니다. 부모 변경 요청은 모의 2차 승인 전까지 제안 상태입니다. |
| 4 | 출력 경로의 `report.json`과 `next-plan.json` | 휴식일 제외, 다른 아이와의 데이터 격리, SQLite 재개 후 기록 유지, 중복 처리, 누적 선호의 다음 추천 반영을 확인합니다. |
| 5 | 키가 설정된 셸에서 `python -m examples.ai_demo --live` | 추천은 `bloomy-rag-llm-v1`, 메모는 `bloomy-intent-llm-v1`, 코칭은 `bloomy-coach-llm-v1`입니다. 오프라인 시연에는 각각 로컬 버전이 표시됩니다. |

통합 시연의 카드 승인과 반영은 JSON 모의 백엔드가 담당합니다. `data/local/integration-runs/`의 매 실행은 새 SQLite 파일과 보고서를 생성합니다.
