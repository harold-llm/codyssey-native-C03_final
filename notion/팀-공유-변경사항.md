## 2. 통합 앱 `learning/` (신규, Apple 뉴스룸 스타일)

- **아이 학습 + 부모 코칭 루프**를 하나의 앱으로 통합했습니다.
- Apple 뉴스룸 스타일 · **다크모드** · **반응형**.
- 흐름: 로그인 → 온보딩(프로필+진단) → 4주 계획 승인 → 오늘(카드+단어/표현) → 부모 피드백 → AI 코치 메시지 → 리포트
- **루트 `/`는 `/learning/`으로 리다이렉트**됩니다. 옛 루트 앱(`app.js`·`style.css`)은 **삭제**했습니다.

> **F**: 앞으로 UI 수정은 `learning/`에서 하시면 됩니다. (`learning/index.html`, `learning/css/style.css`, `learning/js/app.js`, `learning/js/content.js`)

## 3. 핵심 AI 연결

### ① 커리큘럼 추천 = **RAG 연결** (A 담당 영역)
- `Bloomy-AI/`의 RAG 엔진을 `backend/ai_bridge.py`로 백엔드에 연결했습니다.
- 계획 생성 시 `source = rag_onboarding` (RAG 사용), 실패 시 **규칙 기반으로 자동 폴백**.
- RAG가 콘텐츠명을 인용해 4주 계획 + 학습 방법 설명을 생성합니다.

### ② 코치 = **3단계 Agent** + **Claude(LLM)**
- 의도 분류 → 규칙 분기(C→B→A) → 메시지 생성.
- **Claude(Anthropic) 직접 연결** 추가: `BLOOMY_LLM_PROVIDER=anthropic` + `ANTHROPIC_API_KEY`.
- LLM 실패 시 **룰베이스 코치로 자동 폴백**(서비스 안 멈춤).

> **A**: RAG 품질·프롬프트 보정은 `Bloomy-AI/`와 `backend/coach.py`에서 이어가면 됩니다.

## 4. 카탈로그 canonical 62개 (A/F/Q 협업)

- `backend/data/catalog.json`을 **canonical 스키마**로 재작성했습니다.
- **62개**, **나이별 15+ 충족**(4세 27 · 5세 42 · 6세 43 · 7세 32), **L1~L5**.
- 필드: `id, title, age_min, age_max, level, skill(영문), type(영문), provider, link(https), session_minutes, expert_note, trust_source, task, check_point`
- **AI 모듈 검증(`validate_catalog`) 통과**.

> ⚠️ `expert_note`/`trust_source`는 현재 **템플릿 기반**입니다. **실제 전문가 검수 기록**은 A가 채워야 합니다(기획서 7.3).

## 6. 배포 (Vercel + Neon Postgres)

- **URL**: https://codyssey-native-c03-final.vercel.app
- **DB**: Neon Postgres (`DATABASE_URL`). 가입·아이·계획·피드백·코치 메시지가 **Neon에 영구 저장**됩니다.
- **Framework Preset**: `FastAPI` (필수 — "Other"면 `/api/*`가 404 납니다)
- **환경변수**(Vercel): `DATABASE_URL`, `BLOOMY_PEPPER`, `CRON_SECRET`, `ANTHROPIC_API_KEY`, `BLOOMY_LLM_PROVIDER=anthropic`, `BLOOMY_LLM_MODEL`
- 크론: 매일 00:00 UTC(=09:00 KST) `/api/cron`

> ⚠️ **`BLOOMY_PEPPER`는 절대 바꾸지 마세요.** 바꾸면 기존 가입자 비밀번호가 전부 무효화됩니다.

## 8. 주의사항 (로컬 개발)

- **로컬 `.venv`가 Python 3.9**라 FastAPI 경로(`uvicorn api.index:app`)가 안 돕니다. 필요 시 **3.12+로 재생성**하세요. (표준 서버 `python3 backend/main.py`는 정상)
- **로컬 SQLite(`backend/bloomy.db`)와 배포 Neon DB는 별개**입니다. 로컬 계정은 배포 사이트에 없습니다.
- 코드 수정 후 `git push`만 하면 **Vercel 자동 재배포**됩니다(데이터는 Neon에 유지).
- `Bloomy-AI/` 모듈이 저장소에 포함됐습니다(예제/테스트는 타입검사·배포 번들에서 제외).
