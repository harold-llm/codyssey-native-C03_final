## 집계

| 구분 | 인원/건수 | 실사용자 집계 |
|---|---|---|
| 배포 앱을 사용하고 의견을 준 보호자 | **6명** (모두 다른 가정) | ✅ 포함 |
| 오늘의 동요를 제안한 테스터 | 1명 (P6 보호자) | ✅ P6로 이미 포함 (중복 집계 안 함) |
| 피드백 시트 익명 응답 | 2건 | ➖ 신원·중복 확인 불가로 제외 |
| 팀원 의견 (F 박진성, 시트 2건) | 1명 | ❌ 내부 의견이라 제외 |
| 사용자 관점 피드백 보고서 속 "아빠 관점 의견 예시" | 1건 | ❌ 보고서가 가정해 쓴 예시라고 밝혀 제외 |

미션 기준(실사용자 5명 이상)은 확인된 보호자 6명으로 충족합니다. 익명 응답 2건까지 포함하면 최대 8명입니다.
